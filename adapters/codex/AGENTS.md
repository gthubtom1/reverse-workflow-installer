# Codex reverse workflow

For reverse-engineering, security-analysis, protocol, frontend-signature, reconstruction, behavior-comparison, version-tracking, or knowledge-maintenance tasks, read the project `reverse-workflow` Skill before using ordinary tools.

Read the installed receipt at `{{RECEIPT}}`, then follow its `reverse.root`, original `RULES.md`, native router, PRIMARY and scope/case contracts. The project `.agents/skills/reverse-workflow/SKILL.md` is the task entry; REA is an analysis backend selected by the reverse router, and Spec Kit is used only when the independent project needs its own specification and task contract.

Do not install or invoke Pi-only profiles, shell-guard, Craft-Pi, or Pi package registrations in Codex. If an implementation batch explicitly selects upstream Craft Anything for Codex, keep its MCP and approval/consent configuration under the Codex host contract and return the candidate to the original reverse/Spec workflow.
