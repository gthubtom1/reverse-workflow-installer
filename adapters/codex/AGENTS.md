# Codex reverse workflow

For reverse-engineering, security-analysis, protocol, frontend-signature, reconstruction, behavior-comparison, version-tracking, or knowledge-maintenance tasks, read the global Codex `reverse-workflow` Skill before using ordinary tools.

Read the installed receipt at `{{RECEIPT}}`, then follow its `reverse.root`, original `RULES.md`, native router, PRIMARY and scope/case contracts. The global Codex Skill at `{{CODEX_SKILL_ENTRY}}` is the task entry. REA is an analysis backend selected by the reverse router, and Spec Kit is used only when an explicitly selected independent project needs its own specification and task contract.

Do not install or invoke Pi-only profiles, shell-guard, Craft-Pi, Pi package registrations, Impeccable Pi resources, or the optional Pi local packages in Codex. If an implementation batch explicitly selects upstream Craft Anything for Codex, keep its MCP and approval/consent configuration under the Codex host contract and return the candidate to the original reverse/Spec workflow.
